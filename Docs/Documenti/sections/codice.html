const handleFinishWorkout = async () => {
  // 1. Calcolo Punti (Gamification)
  const pointsUpdate = getPointsUpdate(userData, 'WORKOUT_COMPLETED', true);
  const pointsEarned = Object.keys(pointsUpdate).length > 0 ? POINTS_MAP.WORKOUT_COMPLETED : 0;

  const workoutData = {
    userId: currentUser.uid,
    day: dayName,
    exercises: /* ... dati esercizi ... */,
    totalVolume: Math.round(totalVolume),
    completedAt: serverTimestamp()
  };

  try {
    // 2. Salvataggio nella sub-collection dell'utente
    await addDoc(collection(db, 'users', currentUser.uid, 'user_workouts'), workoutData);

    const userUpdates = {
      totalVolumeLifted: increment(Math.round(totalVolume)),
      totalWorkoutsCompleted: increment(1),
      ...pointsUpdate,
    };

    // 3. Aggiornamento statistiche globali utente
    await updateDoc(doc(db, 'users', currentUser.uid), userUpdates);
    setFinished(true);
  } catch (error) { ... }
};

Cosa fa questo codice?

Questo snippet gestisce il completamento di un allenamento:

  • Gamification: Utilizza getPointsUpdate per verificare se l'utente ha diritto a punti esperienza (XP) per l'allenamento di oggi.
  • Scrittura Firebase: Salva i dettagli dell'allenamento in una sotto-collezione user_workouts dedicata.
  • Aggiornamento Profilo: Aggiorna in modo atomico (tramite increment) le statistiche globali dell'utente, come il volume totale sollevato e i punti XP, usando un singolo documento.
Autenticazione Sicura con Google
AuthContext.jsx 
const loginWithGoogle = async () => {
  const provider = new GoogleAuthProvider();
  try {
    const result = await signInWithPopup(auth, provider);
    // Verifica se l'utente esiste già nel database
    const userDoc = await getDoc(doc(db, 'users', result.user.uid));
    
    if (!userDoc.exists()) {
      // Se è un nuovo utente, inizializza il documento
      await setDoc(doc(db, 'users', result.user.uid), {
        email: result.user.email,
        name: result.user.displayName,
        createdAt: serverTimestamp(),
        points: 0
      });
    }
  } catch (error) {
    console.error('Login failed:', error);
  }
};

Gestione Utenti (SSO)

Questo blocco mostra come Liftly gestisce l'accesso tramite Google:

  • Utilizza Firebase Auth con il metodo del popup per un'esperienza fluida.
  • Verifica l'esistenza dell'utente per differenziare tra Login e Registrazione.
  • Se l'utente è nuovo, crea automaticamente il profilo associato nel database Firestore con i dati di base.
